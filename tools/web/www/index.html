Get the most out of your browser

      
    
        
  • Use the latest Chrome, Edge or Brave on a desktop or laptop (WebGPU is required).
    •

    • 
        
  • On laptops, make the browser use your dedicated GPU (Windows Settings › Display › Graphics › High performance).
    • 
        
  • Close other tabs and heavy apps so the game gets more GPU memory and RAM. 16 GB RAM recommended.
    • 
        
  • The first load downloads the game files; later visits load faster from your browser's cache.
