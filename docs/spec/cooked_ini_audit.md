## Caveats (read first)

* **Platform.** Every line is the value the cooker saw while cooking for Mac. A Windows-only ini (`WindowsEngine.ini` and so on) could still override a key. Evidence against that: the `Windows` and `WindowsNoEditor` DeviceProfiles define no CVars (ini L5587-5590). The Scalability, Input and Game sections have no platform layer in 4.16 Fortnite.
* **Coverage.** Only sections the cooker read are listed. A missing key is not proof that it is unset at run time. Epic's CloudStorage hotfix inis (`DefaultEngine.ini` / `DefaultGame.ini` pushed by MCP) and per-user `GameUserSettings.ini` are not covered. Anything those set is NOT-IN-FILE.
* **Classes.**
  * CONFIRMED: the code matches.
  * MISMATCH: the code differs from the file, with the real value given.
  * NOT-IN-FILE: the file does not have the key.
  * STALE-DOC: the claim "ini is encrypted, unreadable" is now outdated, but no value depends on it.
* **Severity.**
  * HIGH: gameplay feel or a visible difference every frame.
  * MED: a visible or behavioural difference in common cases.
  * LOW: an edge case or cosmetic.
  * INFO: documentation only.

Notes on M5. The UE input path is `delta x AxisConfig.Sensitivity (0.07) x InputYawScale (2.5)`, then the FOV scaling (`x FOV x 0.01111`). At the 80 deg hold FOV that gives 0.07 x 2.5 x 0.889 = **0.1556 deg/count** of yaw, about 2x the port's 0.077. That matches the "x2.222 per unit" figure the community uses for legacy Fortnite. Pitch uses `InputPitchScale` -1.75 (sign: mouse-up looks up through the `LookUp` mapping Scale=-1, L2003), so pitch is 0.7x yaw before any native compensation. Before a fix, check in the exe whether `UFortPlayerInput` replaces `AxisProperties.Sensitivity` with the user's `MouseSensitivity` slider (the slider default 0.07 is equal to the AxisConfig value, which suggests it does).

### Key bindings: which preset is the PC default, and why

* L2206 `FortPlayerInput:DefaultPresetNameAthena:0=ConfigD_Athena` sets the BR default preset (L2205 `DefaultPresetName=ConfigD` is the Save the World one, with `bEnabledForAthena=false`).
* `D`, `E` and `F` are controller layouts:
  * ConfigD_Athena: FriendlyName "Standard" (L2589)
  * ConfigE_Athena: "Quick Builder"
  * ConfigF_Athena: "Combat Pro"
  * All three have `bEnabledForAthena=true`.
* Their keyboard and mouse mappings are almost identical. Diffing the non-gamepad ActionMappings: E lacks `Crouch LeftControl` and F lacks `PushToTalk Y`. So ConfigD_Athena is the PC keyboard default by both config and content.
* Shared settings: `HoldInputTime 0.25` (L2597), `HoldCraftAmmoTime 0.75` (L2598), `NumActiveTrapSlots 1` (L2594), `bEditModeUsableFromCombatMode true` (L2596).

* `ConsoleKeys=Tilde` (L1980). `bEnableMouseSmoothing=true` (L1971); the port has no mouse smoothing (unchecked; a candidate item).

The full KBM table for ConfigD_Athena is in S8 above (ini L2627-2761). The rest of it:
* Picker: `PickerConfirm` LMB; `PickerCancel` RMB / B / N / T / Escape; `PickerOption1-8` = 1-8; `PickerNext/Previous` = wheel up/down (L2692-2707).
